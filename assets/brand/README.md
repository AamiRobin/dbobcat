# DBobcat brand icon

A 3D database cylinder with a query-builder badge on a blue rounded tile.

## Files

- `dbobcat-1024.png` — canonical source (1024×1024 RGBA, square, transparent corners). All app icons are generated from this.
- `dbobcat-1024-macos.png` — macOS-only derivative (1024×1024, fully opaque, edge-to-edge). Generated by `scripts/make-macos-icon.ts`; don't edit by hand.
- `dbobcat-app-icon.png` — 512×512 export used in `README.md`.

## Regenerating app icons

After replacing `dbobcat-1024.png`, run both of these in order:

1. Regenerate the Windows/Linux icons from the rounded tile:

   ```sh
   bunx tauri icon assets/brand/dbobcat-1024.png
   ```

   This rewrites everything in `src-tauri/icons/` (`icon.ico` and the PNG sizes referenced by `tauri.conf.json`). It also emits `ios/` and `android/` icon sets — delete those folders, this app is desktop-only.

2. Rebuild the macOS icon from the full-bleed variant (step 1 clobbers it with the rounded tile, which is wrong for macOS):

   ```sh
   bun scripts/make-macos-icon.ts
   ```

   macOS 26+ masks app icons into its own squircle and wraps artwork that doesn't fill the canvas in an auto-generated frame. The rounded tile must therefore never ship inside `icon.icns` as-is — the .icns is compiled from the opaque, edge-to-edge `dbobcat-1024-macos.png` instead.

   `dbobcat-1024-macos.png` is a platform adaptation, not a different design: the tile's artwork pasted over a background extended from the tile's own edge pixels (its baked-in rounded corners and drop shadow excluded). If you re-export the artwork as a true full-bleed square — no rounded corners, no margins, fully opaque, e.g. from the image generator or design tool the tile came from — compile it directly instead of the derived one:

   ```sh
   bun scripts/make-macos-icon.ts assets/brand/dbobcat-fullbleed.png
   ```

   Next step up from there is Apple's Icon Composer and its `.icon` format (layered icon, real Liquid Glass treatment). tauri-bundler doesn't support `.icon` files yet — it only copies a listed `.icns` or packs PNGs into one — so a full-bleed `.icns` is the correct format until upstream support lands.

## Other exports

- `src/assets/dbobcat-logo.webp` — About dialog logo (128×128), shown at 24 px.
- `public/dbobcat.png` — favicon (64×64), referenced from `index.html`.

Regenerate them from the source at any size with e.g. Pillow or sips, keeping the filenames so no code changes are needed.
